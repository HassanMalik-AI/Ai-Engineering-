## 1. What is GMM?

**Gaussian Mixture Model (GMM)** is a probabilistic model that assumes all data points are generated from a **mixture of a finite number of Gaussian (Normal) distributions** with unknown parameters.

> 📌 It is a **soft clustering** algorithm — instead of assigning each point to exactly one cluster (like K-Means), GMM gives each point a **probability of belonging** to each cluster.

### Key Idea:
- The entire dataset is assumed to be a mix of `K` Gaussian distributions.
- Each Gaussian represents one cluster.
- Each data point has a probability of belonging to each Gaussian.

---

## 2. Intuition Behind GMM

Imagine you have heights of people in a room — the data has two peaks (short people and tall people). If you plot a histogram, it might look like **two overlapping bell curves**.

GMM says:  
> "This data was generated by **mixing** two Gaussian distributions — let me figure out what those Gaussians look like!"

### Visual Intuition:
```
         Cluster 1       Cluster 2
            🔔               🔔
           /  \             /  \
          /    \           /    \
---------/------\---------/------\---------
                  overlap here
```

Points in the overlap region get **shared membership** — that's the power of soft clustering.

---

## 3. Mathematical Foundation

### 3.1 Gaussian Distribution (Single)

A single Gaussian (Normal) distribution for a data point **x** is:

```
N(x | μ, Σ) = (1 / √(2π|Σ|)) * exp(-0.5 * (x - μ)ᵀ Σ⁻¹ (x - μ))
```

Where:
- `μ` = mean vector (center of the distribution)
- `Σ` = covariance matrix (spread/shape of the distribution)
- `|Σ|` = determinant of covariance matrix

### 3.2 Mixture of Gaussians

The **probability density** of a data point `x` under a GMM is:

```
p(x) = Σ_{k=1}^{K}  π_k * N(x | μ_k, Σ_k)
```

Where:
- `K` = number of Gaussian components (clusters)
- `π_k` = mixing coefficient (weight) for component k
- `N(x | μ_k, Σ_k)` = Gaussian density for component k
- `Σ π_k = 1` and `π_k ≥ 0` (valid probability weights)

### 3.3 Responsibility (Posterior Probability)

The probability that data point `x_i` belongs to component `k`:

```
r_{ik} = P(z_i = k | x_i) = [π_k * N(x_i | μ_k, Σ_k)] / Σ_{j=1}^{K} [π_j * N(x_i | μ_j, Σ_j)]
```

This is called the **responsibility** of component `k` for data point `i`.

### 3.4 Log-Likelihood

The objective is to **maximize** the log-likelihood:

```
log L(θ) = Σ_{i=1}^{N} log [ Σ_{k=1}^{K} π_k * N(x_i | μ_k, Σ_k) ]
```

## 4. GMM vs K-Means

| Feature | K-Means | GMM |
|---|---|---|
| **Cluster Shape** | Spherical (circle) | Elliptical (any shape) |
| **Assignment Type** | Hard (0 or 1) | Soft (probability) |
| **Probabilistic** | No | Yes |
| **Parameters Learned** | Centroids only | μ, Σ, π per component |
| **Overlap Handling** | Poor | Excellent |
| **Sensitivity to Outliers** | High | Moderate |
| **Speed** | Faster | Slower |
| **Use case** | Well-separated clusters | Overlapping / irregular clusters |

### Example:

```python
# K-Means: Hard assignment
# Point A → Cluster 1 (100%)

# GMM: Soft assignment
# Point A → Cluster 1 (70%), Cluster 2 (30%)
```

## 5. The EM Algorithm (Expectation-Maximization)

GMM is fitted using the **EM Algorithm**, which alternates between two steps:

### Step 0: Initialization
- Randomly initialize `π_k`, `μ_k`, `Σ_k` for each component.

---

### Step 1: E-Step (Expectation)
**Compute responsibilities** — how much each Gaussian is "responsible" for each data point.

```
r_{ik} = [π_k * N(x_i | μ_k, Σ_k)] / Σ_j [π_j * N(x_i | μ_j, Σ_j)]
```

For each data point `i`, we compute a probability vector of size `K`.

---

### Step 2: M-Step (Maximization)
**Update parameters** using the computed responsibilities:

```
# Effective number of points assigned to component k
N_k = Σ_i r_{ik}

# Update mean
μ_k = (1/N_k) * Σ_i r_{ik} * x_i

# Update covariance
Σ_k = (1/N_k) * Σ_i r_{ik} * (x_i - μ_k)(x_i - μ_k)ᵀ

# Update mixing coefficient
π_k = N_k / N
```

---

### Step 3: Check Convergence
- Compute log-likelihood.
- If the change is less than a threshold (e.g., 1e-6), **stop**.
- Otherwise, go back to E-Step.

### EM Algorithm Flow:
```
Initialize θ = {π, μ, Σ}
          ↓
    ┌─────────────────────┐
    │  E-Step:             │
    │  Compute r_{ik}      │
    └────────┬────────────┘
             ↓
    ┌─────────────────────┐
    │  M-Step:             │
    │  Update π, μ, Σ      │
    └────────┬────────────┘
             ↓
    Converged? ──No──→ Loop back
         │
        Yes
         ↓
    Final GMM parameters
```

## 6. Parameters of GMM

Each component `k` has three parameters:

| Parameter | Symbol | Meaning |
|---|---|---|
| **Mean** | `μ_k` | Center of the Gaussian cluster |
| **Covariance** | `Σ_k` | Shape and spread of the cluster |
| **Mixing Weight** | `π_k` | How large/probable this component is |

### Total number of parameters:
```
For D-dimensional data with K components:
- Means: K × D
- Full Covariance: K × D × (D+1)/2
- Weights: K - 1 (last weight = 1 - sum of others)
```

---

## 7. Covariance Types

Scikit-learn GMM supports 4 types of covariance matrices:

### 7.1 `full` (default)
- Each component has its **own full covariance matrix**.
- Most flexible — clusters can be any ellipse with any orientation.
- Most parameters to learn.

```
Σ = [[a, b],    # arbitrary ellipse
     [b, c]]
```

### 7.2 `tied`
- All components **share the same** covariance matrix.
- Different sized clusters but same shape.

### 7.3 `diag`
- Each component has its own **diagonal covariance**.
- Ellipses aligned with axes (no rotation).
- Fewer parameters.

```
Σ = [[a, 0],    # axis-aligned ellipse
     [0, c]]
```

### 7.4 `spherical`
- Each component has a **single variance** (scalar).
- Circular clusters.
- Similar to K-Means.

```
Σ = σ² * I      # circle
```

### Visual Summary:
```
spherical    diag         tied         full
   ●          ⬭           ⬭ ⬭         ⬭ ↗
  ● ●        ⬭  ⬭         ⬭ ⬭        ↗ ⬭
```

## 8. Choosing the Number of Components (K)

### 8.1 BIC (Bayesian Information Criterion) — Lower is better
```
BIC = -2 * log(L) + p * log(N)
```
- `L` = likelihood, `p` = number of parameters, `N` = number of data points
- Penalizes model complexity → prevents overfitting

### 8.2 AIC (Akaike Information Criterion) — Lower is better
```
AIC = -2 * log(L) + 2 * p
```
- Less strict penalty than BIC
- May favor more components

### 8.3 Code to Select K:

```python
from sklearn.mixture import GaussianMixture
import numpy as np

bic_scores = []
aic_scores = []
K_range = range(1, 11)

for k in K_range:
    gmm = GaussianMixture(n_components=k, random_state=42)
    gmm.fit(X)
    bic_scores.append(gmm.bic(X))
    aic_scores.append(gmm.aic(X))

best_k_bic = K_range[np.argmin(bic_scores)]
best_k_aic = K_range[np.argmin(aic_scores)]

print(f"Best K by BIC: {best_k_bic}")
print(f"Best K by AIC: {best_k_aic}")
```

## 9. Advantages & Disadvantages

### ✅ Advantages

1. **Soft Clustering** — each point gets a probability, not just a label.
2. **Flexible Cluster Shapes** — handles elliptical clusters (not just spherical).
3. **Probabilistic Framework** — principled statistical model.
4. **Handles Overlapping Clusters** — gracefully models ambiguity.
5. **Density Estimation** — GMM is also a density estimator, useful for anomaly detection.
6. **Covariance Flexibility** — multiple covariance types for different needs.

### ❌ Disadvantages

1. **Sensitive to Initialization** — poor init can lead to bad local optima.
2. **Assumes Gaussian Shape** — fails if true clusters are non-Gaussian.
3. **Computationally Expensive** — slower than K-Means for large data.
4. **Choosing K** — number of components must be specified.
5. **Singularity Problem** — covariance can collapse (degenerate solutions).
6. **Curse of Dimensionality** — Gaussians are poor fits in very high dimensions.

---

## 10. When to Use GMM

| Situation | Use GMM? |
|---|---|
| Clusters overlap | ✅ Yes |
| Soft cluster membership needed | ✅ Yes |
| Clusters are elliptical | ✅ Yes |
| Need density estimation | ✅ Yes |
| Anomaly detection | ✅ Yes |
| Very large dataset (millions of rows) | ⚠️ Maybe (use mini-batch) |
| Clusters are perfectly spherical | ❌ Use K-Means |
| Very high-dimensional data (>100D) | ❌ Reduce dim first |
| Non-Gaussian clusters (rings, moons) | ❌ Use DBSCAN |

## 11. Implementation from Scratch (NumPy)

```python
import numpy as np

class GMMScratch:
    def __init__(self, n_components=2, max_iter=100, tol=1e-6):
        self.K = n_components
        self.max_iter = max_iter
        self.tol = tol

    def _gaussian(self, X, mean, cov):
        """Compute multivariate Gaussian PDF"""
        D = X.shape[1]
        diff = X - mean
        cov_inv = np.linalg.inv(cov)
        cov_det = np.linalg.det(cov)
        norm = 1.0 / (np.sqrt((2 * np.pi) ** D * cov_det))
        exponent = -0.5 * np.sum(diff @ cov_inv * diff, axis=1)
        return norm * np.exp(exponent)

    def fit(self, X):
        N, D = X.shape
        K = self.K

        # --- Initialization ---
        np.random.seed(42)
        idx = np.random.choice(N, K, replace=False)
        self.means = X[idx]
        self.covs = [np.eye(D)] * K
        self.weights = np.ones(K) / K

        log_likelihood_old = -np.inf

        for iteration in range(self.max_iter):

            # --- E-Step: Compute responsibilities ---
            R = np.zeros((N, K))
            for k in range(K):
                R[:, k] = self.weights[k] * self._gaussian(X, self.means[k], self.covs[k])
            R /= R.sum(axis=1, keepdims=True)  # Normalize

            # --- M-Step: Update parameters ---
            Nk = R.sum(axis=0)  # Effective number per component

            for k in range(K):
                # Update mean
                self.means[k] = (R[:, k] @ X) / Nk[k]

                # Update covariance
                diff = X - self.means[k]
                self.covs[k] = (R[:, k] * diff.T) @ diff / Nk[k]
                self.covs[k] += np.eye(D) * 1e-6  # Regularization

                # Update weight
                self.weights[k] = Nk[k] / N

            # --- Compute log-likelihood ---
            likelihood = np.zeros(N)
            for k in range(K):
                likelihood += self.weights[k] * self._gaussian(X, self.means[k], self.covs[k])
            log_likelihood = np.sum(np.log(likelihood + 1e-300))

            # --- Check convergence ---
            if abs(log_likelihood - log_likelihood_old) < self.tol:
                print(f"Converged at iteration {iteration}")
                break
            log_likelihood_old = log_likelihood

        return self

    def predict_proba(self, X):
        """Return soft assignments"""
        N, D = X.shape
        R = np.zeros((N, self.K))
        for k in range(self.K):
            R[:, k] = self.weights[k] * self._gaussian(X, self.means[k], self.covs[k])
        R /= R.sum(axis=1, keepdims=True)
        return R

    def predict(self, X):
        """Return hard cluster labels"""
        return np.argmax(self.predict_proba(X), axis=1)


# --- Test it ---
from sklearn.datasets import make_blobs

X, y_true = make_blobs(n_samples=300, centers=3, cluster_std=0.6, random_state=42)

gmm = GMMScratch(n_components=3)
gmm.fit(X)
labels = gmm.predict(X)

print("Cluster labels:", np.unique(labels))
print("Means:\n", gmm.means)
```

## 12. Implementation using Scikit-learn

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.mixture import GaussianMixture
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler

# ─────────────────────────────────────────
# 1. Generate Data
# ─────────────────────────────────────────
X, y_true = make_blobs(n_samples=500, centers=4, cluster_std=0.8, random_state=42)
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# ─────────────────────────────────────────
# 2. Find Best K using BIC
# ─────────────────────────────────────────
bic_scores = []
for k in range(1, 10):
    gmm = GaussianMixture(n_components=k, covariance_type='full', random_state=42)
    gmm.fit(X_scaled)
    bic_scores.append(gmm.bic(X_scaled))

best_k = np.argmin(bic_scores) + 1
print(f"Best number of components: {best_k}")

# ─────────────────────────────────────────
# 3. Fit Final GMM
# ─────────────────────────────────────────
gmm = GaussianMixture(
    n_components=best_k,
    covariance_type='full',   # 'full', 'tied', 'diag', 'spherical'
    n_init=10,                # Run 10 times with different inits
    max_iter=100,
    random_state=42
)
gmm.fit(X_scaled)

# ─────────────────────────────────────────
# 4. Predict
# ─────────────────────────────────────────
labels = gmm.predict(X_scaled)           # Hard labels
probs  = gmm.predict_proba(X_scaled)     # Soft probabilities

print("\nCluster labels (first 10):", labels[:10])
print("\nProbabilities (first 3 points):\n", probs[:3].round(3))

# ─────────────────────────────────────────
# 5. Inspect Learned Parameters
# ─────────────────────────────────────────
print("\nMixing Weights:", gmm.weights_.round(3))
print("\nMeans:\n", gmm.means_.round(3))
print("\nCovariances (component 0):\n", gmm.covariances_[0].round(3))

# ─────────────────────────────────────────
# 6. Evaluate
# ─────────────────────────────────────────
print(f"\nBIC:  {gmm.bic(X_scaled):.2f}")
print(f"AIC:  {gmm.aic(X_scaled):.2f}")
print(f"Log-Likelihood: {gmm.score(X_scaled):.4f}")

# ─────────────────────────────────────────
# 7. Anomaly Detection using GMM
# ─────────────────────────────────────────
log_probs = gmm.score_samples(X_scaled)
threshold = np.percentile(log_probs, 2)   # Bottom 2% = anomalies
anomalies = X_scaled[log_probs < threshold]

print(f"\nNumber of anomalies detected: {len(anomalies)}")
```

## 14. Evaluation Metrics

### 14.1 If Ground Truth is Known (Supervised Evaluation)

```python
from sklearn.metrics import adjusted_rand_score, normalized_mutual_info_score, silhouette_score

labels_pred = gmm.predict(X)

# Adjusted Rand Index (range: -1 to 1, higher is better)
ari = adjusted_rand_score(y_true, labels_pred)

# Normalized Mutual Information (range: 0 to 1, higher is better)

```

### 14.2 If Ground Truth is NOT Known (Unsupervised Evaluation)

```python
# Silhouette Score (-1 to 1, higher is better)
```

## 15. Common Pitfalls & Tips

### ⚠️ Pitfall 1: Singular Covariance Matrix
**Problem:** Covariance becomes degenerate (near zero variance in one direction).  
**Fix:** Use `reg_covar` parameter in scikit-learn (adds small value to diagonal).
```python
gmm = GaussianMixture(n_components=3, reg_covar=1e-6)
```

### ⚠️ Pitfall 2: Bad Initialization
**Problem:** EM converges to poor local optimum.  
**Fix:** Use multiple restarts with `n_init`.
```python
gmm = GaussianMixture(n_components=3, n_init=20)
```

### ⚠️ Pitfall 3: Wrong K
**Problem:** Too few or too many components.  
**Fix:** Use BIC/AIC to select K.

### ⚠️ Pitfall 4: Unscaled Features
**Problem:** Features with very different scales dominate distance calculations.  
**Fix:** Always standardize before fitting GMM.
```python
from sklearn.preprocessing import StandardScaler
X = StandardScaler().fit_transform(X)
```

### ⚠️ Pitfall 5: High Dimensions
**Problem:** Gaussians become unreliable in >50 dimensions.  
**Fix:** Reduce dimensions first with PCA.
```python
from sklearn.decomposition import PCA
X = PCA(n_components=10).fit_transform(X)
```

### 💡 Tips for Best Results

| Tip | Why |
|---|---|
| Use `n_init=10` or more | Avoid poor local optima |
| Scale your features | Equal contribution from all features |
| Try different covariance types | Match your data's cluster shapes |
| Use BIC to select K | Principled model selection |
| Reduce dimensions first (PCA) | For high-dimensional data |
| Check convergence warnings | May need more `max_iter` |

## 16. Full End-to-End Project Example

### Problem: Customer Segmentation for E-Commerce

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.mixture import GaussianMixture
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.metrics import silhouette_score

# ─────────────────────────────────────────
# Step 1: Load and Prepare Data
# ─────────────────────────────────────────
np.random.seed(42)
N = 500

data = {
    'age':            np.random.normal(35, 12, N).clip(18, 70),
    'annual_income':  np.random.exponential(50000, N).clip(15000, 200000),
    'spending_score': np.random.uniform(1, 100, N),
    'purchase_freq':  np.random.poisson(5, N),
    'avg_order_value':np.random.normal(150, 80, N).clip(10, 500),
}

df = pd.DataFrame(data)
print("Dataset shape:", df.shape)
print(df.head())

# ─────────────────────────────────────────
# Step 2: Preprocess
# ─────────────────────────────────────────
scaler = StandardScaler()
X_scaled = scaler.fit_transform(df)

# ─────────────────────────────────────────
# Step 3: Dimensionality Reduction (for viz)
# ─────────────────────────────────────────
pca = PCA(n_components=2)
X_2d = pca.fit_transform(X_scaled)
print(f"Explained variance: {pca.explained_variance_ratio_.sum():.1%}")

# ─────────────────────────────────────────
# Step 4: Find Best K
# ─────────────────────────────────────────
bic_scores = []
sil_scores = []
K_values = range(2, 9)

for k in K_values:
    gmm = GaussianMixture(n_components=k, n_init=10, random_state=42)
    gmm.fit(X_scaled)
    labels = gmm.predict(X_scaled)
    bic_scores.append(gmm.bic(X_scaled))
    sil_scores.append(silhouette_score(X_scaled, labels))

best_k = K_values[np.argmin(bic_scores)]
print(f"\nBest K (BIC): {best_k}")

# ─────────────────────────────────────────
# Step 5: Fit Final Model
# ─────────────────────────────────────────
gmm_final = GaussianMixture(
    n_components=best_k,
    covariance_type='full',
    n_init=20,
    random_state=42
)
gmm_final.fit(X_scaled)

# ─────────────────────────────────────────
# Step 6: Get Results
# ─────────────────────────────────────────
labels = gmm_final.predict(X_scaled)
probs  = gmm_final.predict_proba(X_scaled)

df['segment'] = labels
df['confidence'] = probs.max(axis=1)

# ─────────────────────────────────────────
# Step 7: Analyze Segments
# ─────────────────────────────────────────
segment_summary = df.groupby('segment').agg({
    'age': 'mean',
    'annual_income': 'mean',
    'spending_score': 'mean',
    'purchase_freq': 'mean',
    'avg_order_value': 'mean',
    'confidence': ['mean', 'count']
}).round(2)

print("\nSegment Summary:")
print(segment_summary)

# ─────────────────────────────────────────
# Step 8: Anomaly Detection
# ─────────────────────────────────────────
log_probs = gmm_final.score_samples(X_scaled)
threshold = np.percentile(log_probs, 2)
df['is_anomaly'] = log_probs < threshold

print(f"\nAnomalies found: {df['is_anomaly'].sum()}")

# ─────────────────────────────────────────
# Step 9: Final Scores
# ─────────────────────────────────────────
print(f"\nModel Performance:")
print(f"  BIC:              {gmm_final.bic(X_scaled):.2f}")
print(f"  AIC:              {gmm_final.aic(X_scaled):.2f}")
print(f"  Log-Likelihood:   {gmm_final.score(X_scaled):.4f}")
print(f"  Silhouette Score: {silhouette_score(X_scaled, labels):.4f}")
```

## 17. Interview Questions

### Q1: What is the difference between GMM and K-Means?
> **K-Means** does hard assignment and assumes spherical clusters. **GMM** does soft probabilistic assignment, can model elliptical clusters, and learns the full covariance structure.

### Q2: What algorithm is used to train GMM?
> The **Expectation-Maximization (EM)** algorithm — alternating between computing responsibilities (E-step) and updating parameters (M-step) until convergence.

### Q3: What does "soft clustering" mean in GMM?
> Each data point is assigned a **probability vector** over all clusters, rather than a single hard label. A point might be 70% in cluster 1 and 30% in cluster 2.

### Q4: How do you choose the number of components in GMM?
> Use **BIC (Bayesian Information Criterion)** or **AIC** — choose K that minimizes these values. BIC penalizes complexity more strongly.

### Q5: What is the responsibility in GMM?
> The posterior probability `r_{ik}` = probability that data point `i` was generated by component `k`. Computed in the E-step.

### Q6: Why might GMM fail?
> - Bad initialization (EM finds local optima)  
> - Covariance singularity (numerical issues)  
> - Non-Gaussian cluster shapes  
> - High-dimensional data (curse of dimensionality)

### Q7: How can GMM be used for anomaly detection?
> Fit GMM on normal data. Score new points using `score_samples()`. Points with **very low log-probability** are anomalies.

### Q8: What is the singularity problem in GMM?
> If a Gaussian collapses onto a single data point, its covariance goes to zero, making the likelihood blow up to infinity. Fix: regularize with small `reg_covar`.
